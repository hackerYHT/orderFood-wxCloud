# 小票打印机接入指南

本小程序使用 **大趋智能 IoT 云打印 API** 驱动 WiFi 热敏小票机，下单后自动打印厨房/收银小票。

---

## 一、硬件准备

### 推荐设备

- **品牌**：大趋智能 WiFi 云打印机
- **购买渠道**：[大趋智能开放平台](https://open.trenditiot.com) 或官方授权渠道
- **参考价格**：约 200–300 元/台
- **网络要求**：打印机需连接店铺 WiFi，并保持在线

### 开箱后需记录的信息

打印机机身或包装盒上通常印有：

| 字段 | 说明 | 示例 |
|------|------|------|
| **SN（设备编号）** | 打印机唯一序列号 | `SP0123456789` |
| **KEY（绑定码）** | 用于绑定到云平台的密钥 | `abcd1234` |

> 绑定码 KEY 只显示一次或需从大趋智能后台查看，请妥善保存。

## 二、云平台账号配置

### 1. 注册大趋智能开放平台

1. 访问 [https://open.trenditiot.com](https://open.trenditiot.com)（开发文档：[https://trendit.cn/dev](https://trendit.cn/dev)）
2. 注册并登录开发者账号
3. 在控制台创建应用，获取：
   - **AppID**
   - **AppSecret**

### 2. 配置云函数 `printManage`

编辑 `cloudfunctions/printManage/index.js`，填入你的凭证：

```javascript
const appid = '你的AppID'
const appsecret = '你的AppSecret'
```

### 3. 上传云函数

在微信开发者工具中：

1. 右键 `cloudfunctions/printManage` → **上传并部署：云端安装依赖**
2. 同样上传 `cloudfunctions/printBack`（打印结果回调）
3. 同样上传 `cloudfunctions/doBuy`（下单后触发打印）

### 4. 配置打印回调（可选但推荐）

在云开发控制台 → 云函数 → `printBack` → 触发器/HTTP 访问：

- 将 `printBack` 的 HTTP 触发地址配置到大趋智能开放平台的「回调地址」
- 回调用于更新订单的 `printStatus`（2=成功、3=失败、4=取消）

## 三、小程序管理后台绑定打印机

### 进入管理后台

1. 打开小程序，进入底部 **「设置」** 页
2. 在页面 **右下角空白区域连续快速点击 5 次**
3. 首次使用设置管理员密码（至少 6 位），之后输入密码登录
4. 进入 **系统设置 → 打印机管理**

### 绑定步骤

1. 确保打印机已通电并连接 WiFi（指示灯正常）
2. 点击 **「绑定打印机」**
3. 填写：
   - **设备编号（SN）**：打印机 SN
   - **绑定码（KEY）**：打印机 KEY
   - **设备名称**：自定义，如「厨房打印机」
4. 点击确认绑定

绑定成功后：

- 打印机信息会保存到云数据库 `printer` 集合
- 同时通过大趋智能 API 完成云端注册
- 可在管理页查看在线状态、测试打印、调节浓度/速度/音量

### 测试打印

绑定完成后，点击 **「测试打印」**，确认小票机能正常出纸。

## 四、打印触发流程

```
店员选菜 → 确认打印 → doBuy 云函数创建订单 → 调用 printManage 打印小票
                                              ↓
                                    printBack 回调更新 printStatus
```

- 系统只使用 `printer` 集合中的 **第一台** 打印机
- 堂食订单播报音源代码：`16`
- 打包订单播报音源代码：`19`
- 若未绑定打印机，订单仍会创建，但不会打印（前端提示「未连接打印机」）

## 五、数据库集合

需在云开发控制台创建 `printer` 集合（权限建议：仅管理员可写，或按项目 README 配置）：

```json
{
  "sn": "设备编号",
  "key": "绑定码",
  "name": "打印机名称",
  "density": 6,
  "printSpeed": 2,
  "volume": 3,
  "createTime": "服务器时间"
}
```

## 六、常见问题

### 绑定失败

- 检查 SN、KEY 是否输入正确（注意大小写、无多余空格）
- 确认 `printManage` 云函数中的 AppID/AppSecret 已正确填写并已重新上传
- 确认打印机已联网

### 下单成功但不打印

- 管理后台查看打印机是否 **在线**
- 云开发控制台 → 云函数 → `doBuy` / `printManage` 日志，查看错误信息
- 确认 `printer` 集合中有一条有效记录

### 打印内容乱码或格式异常

- 在打印机管理中调整 **打印浓度**（建议 6）
- 确认使用的是大趋智能兼容的热敏纸（58mm 或 80mm，视机型而定）

### 测试打印成功，正式订单不打印

- 确认 `doBuy` 云函数已更新并重新部署（新版会在每次下单后立即打印）
- 检查云函数调用 `printManage` 是否返回 `success: true`
